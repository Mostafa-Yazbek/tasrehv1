# مشروع مصرّح — Vanilla Frontend

هذه الحزمة مستقلة وتستخدم **HTML5 وCSS3 وVanilla JavaScript فقط**. لا تحتاج إلى Node.js أو npm أو Vite أو أي عملية بناء، ولا تحتوي على React أو JSX أو مكتبات خارجية.

## التشغيل المباشر

افتح ملف `index.html` مباشرة في أي متصفح حديث، ثم استخدم البطاقات للانتقال إلى صفحات التصاريح. تظل الصور والخطوط محلية داخل مجلد `assets`، لذلك تعمل الهوية البصرية دون اتصال بخدمات خارجية.

## هيكل الملفات

| المسار | الغرض |
|---|---|
| `index.html` | الصفحة الرئيسية «مصرّح» وبطاقات أنواع التصاريح. |
| `pages/transport.html` | نموذج تصريح النقل وفق واجهة إضافة طلب الترخيص المرفقة. |
| `pages/excavation.html` | واجهة تصريح الحفر والخطوات الإدارية السبع. |
| `pages/pouring.html` | واجهة تصريح الصب: المكان والموقع والعمق. |
| `css/variables.css` | متغيرات الهوية والخطوط المرجعية. |
| `css/style.css` | كامل تنسيق CSS3 والاستجابة للشاشات المختلفة. |
| `js/main.js` | التفاعل المحلي: إضافة وحذف المواد ورسائل حفظ تجريبية. |
| `assets/` | الصور والنمط والخطوط المحلية المستخدمة في الواجهة. |

> الأزرار لا تتصل بخادم أو قاعدة بيانات؛ الحفظ محلي/شكلي فقط كما هو مطلوب للمرحلة الحالية.
